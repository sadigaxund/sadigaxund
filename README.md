## 📌 About Me 
<a href="https://git.io/typing-svg"><img src="https://readme-typing-svg.demolab.com?font=Fira+Code&pause=1000&width=435&lines=Software+Engineer;Big+Data+Nerd;Open-Source+Builder;Coffee+%E2%86%92+Data;Always+Learning;Breaking+Prod+Since+2021" alt="Typing SVG" /></a>

Data Engineer with 3+ years across platform and delivery. Integrated Apache Spark, Iceberg, and Trino into an in-house orchestration platform at KDM Force, opening federated lakehouse queries without re-ingesting to the warehouse. On the delivery side, designed multi-source ingestion pipelines processing 80M+ customer reviews for national tourism analytics — Kafka decoupling ingest from transform, Spark consuming into a SQL Server warehouse with dimensional and SCD modeling that held up under messy real-world OTA data.
